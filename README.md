# Pokelike Companion

Extensión de Chrome que ayuda en las partidas de Story de [pokelike.xyz](https://pokelike.xyz): simulación de combates con el motor del propio juego, ruta recomendada, capturas, tutor, pasivas, objetos, megas y auras de Kalos.

## Cómo se actualiza
La carpeta `extension/` es un cargador. Al abrir el juego descarga `companion.js` y `companion.css` de la rama `main` de este repositorio. Si GitHub no responde, usa la copia que lleva dentro.

Para publicar una versión nueva basta con actualizar `companion.js` y `companion.css` en `main`.

## Instalar
1. Descarga la carpeta `extension/`.
2. En `chrome://extensions` activa el modo de desarrollador y pulsa "Cargar descomprimida".
3. Elige la carpeta `extension/` y recarga pokelike.xyz.
